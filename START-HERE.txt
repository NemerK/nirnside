Nirnside — start here
=====================

Windows (the usual way)
  Download Nirnside.exe from GitHub Releases and double-click it.
  https://github.com/NemerK/nirnside/releases/latest

  A short wizard installs Nirnside on this PC and opens a browser.
  You do not install Node.js, Visual Studio, or Python.

  If Windows says it protected your PC: More info → Run anyway.

macOS / Linux, or if you already have Node
  Windows:  double-click  start-nirnside.cmd
  Mac/Linux:  chmod +x start-nirnside.sh && ./start-nirnside.sh

In the game, once
  Character select → AddOns → enable Nirnside Snapshot.
  Log out (or /reloadui). Zoning / instances do not snapshot.

  If Setup did not find ESO by itself, pick
  Documents\Elder Scrolls Online  (liveeu = EU, live = NA).

Updates
  Open Nirnside again (the desktop shortcut, the exe, or start-nirnside).
  It pulls the latest app and addons from GitHub. Your account database
  in the data folder is never overwritten. In game, /reloadui after an
  addon update.

Nirnside never asks for an ESO password and never uploads anything.
